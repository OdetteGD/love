# 3D demo assets

Place project-owned demo assets in this directory, grouped by scene (for example `anime-courtyard/`, `pbr-showcase/`, and `water-sky/`). Keep source files and license records alongside the assets.

## Asset checklist
- GLB/GLTF model and texture paths verified against the chosen 3DreamEngine revision.
- PBR maps supplied where needed: albedo/base color, normal, roughness, metallic, AO and emission.
- Rig, skeleton and animation compatibility checked before importing animated characters.
- Record creator, source URL, license, attribution and modification status for each external asset.
- Optimize texture resolution, mesh complexity and animation size for Android.
- Do not commit copyrighted marketplace models or generated assets unless their license grants redistribution.

This folder intentionally does not ship placeholder models or claim that high-detail assets have been added.
